# Portfolio

This project is a personal web portfolio, meticulously developed to showcase my abilities as a full stack programmer,
specializing in Laravel for the backend and React for the frontend. The platform serves as a comprehensive showcase
where not only my technical skills in modern web development are highlighted, but also my soft skills, which are crucial
for teamwork and problem-solving. Furthermore, the website includes a dedicated section for past projects, providing
concrete examples of my experience and contributions in the programming world.

<img src="/src/docs/home-screenshot.png" width="750px" alt="home-screenshot">

## ✅ Features

- Show information about me
- Show technical skills (hard skills)
- Show soft skills
- Show contact info
- Show past projects

_(All static)._

## ⚙️ Tech Stack

- React 19
- React Router 7.5
- React Router Hash Link 2.4
- Tailwindcss 3.4
- Vite 5.4
- Lenis 1.3
- Motion 12.15
- React Slick 0.30
- Slick Carousel 1.8

## 💾 Installation

Install and run

1. Clone and move to folder

```bash
$ git clone git@github.com:abrahamuchos/portfolio-web.git
$ cd portfolio-web
```

2. Install dependencies

```bash
$  npm install
```

3. Run dev `npm run dev` or run to production `npm run build`
